# A-Star-JS

__My implementation of the A* pathfinding algorithm in pure JavaScript.__

The [Wikipedia Pseudocode](https://en.wikipedia.org/wiki/A*_search_algorithm?scrlybrkr=f09c082e#Pseudocode) was used to implement this, and it would have been much harder without it.

While this repo contains both `AStar1.js` and `AStar2.js`, only use `AStar2.js`. It is the only working revision yet.


*I sincerely apologize for the overuse of comments in the script files. I'm working on it, and I'll get a revision without the annoyances soon.*
